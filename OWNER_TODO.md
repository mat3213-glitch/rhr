## 1. Куки X/Twitter — 10 минут, открывает целый источник

**Зачем.** Коллектора X у RHR нет вообще, а это единственное место, где обсуждение живёт
в моменте. Платный xAI я снял 03.08 (падал ежедневно, дублируя бесплатный канал).
Официальный API — от $200/мес. Куки открывают чтение бесплатно.

**Что делать:**
1. Поставь расширение **Cookie-Editor** (Chrome/Firefox).
2. Зайди на `x.com` под своим аккаунтом.
3. Открой Cookie-Editor → Export → **Export as JSON**.
4. Из выгрузки нужны ровно два значения: **`auth_token`** и **`ct0`**.
5. Пришли их мне в личку в TG **одним сообщением** в виде:
   ```
   TWITTER_AUTH_TOKEN=...
   TWITTER_CT0=...
   ```
   Либо положи файл на ЯД: `Content factory/secrets/x_cookies.json` — я заберу оттуда.

**Что сделаю я:** пропишу их в секреты репо, подниму коллектор `x_search` по образцу
`hn_search`, добавлю в `ask` третьим источником. Проверка — `python run.py ask "…" --sources x`.

⚠️ Куки живут до смены пароля и до явного выхода из сессии. Если разлогинишься на этом
устройстве — куки умрут, нужны будут новые.

## 2. Куки Reddit — те же 10 минут, чинит половину источника

**Зачем.** Сейчас Reddit читается лентой `old.reddit.com/r/*/new/.rss` — только новые посты
выбранных сабреддитов, **без поиска и без комментариев**. А ценное на Reddit живёт именно
в комментариях и находится поиском. Анонимный поиск Reddit закрыт (403 с датацентра).

**Что делать:** то же, что в п.1, но на `reddit.com`. Нужна вся строка cookie
(там `reddit_session` и сопутствующие) — просто пришли JSON-выгрузку целиком, я разберу.

**Что сделаю я:** коллектор `reddit_search` (поиск + комментарии верхнего уровня),
подключу в `ask`.

## 3. Решение по темам мониторинга — 5 минут, только твоё

**Зачем.** Плановый скан сейчас ищет по терминам, зашитым в `config/sources.yaml`:
`passive income`, `make money online`, `micro saas`, `ai wrapper`, `indie hacker revenue`.
Это темы «воронки продуктов» из первоначального замысла RHR. Под контент-фабрику они
мимо: нам нужны референсы, приёмы монтажа, находки по генерации видео, живые инструменты.

**Что делать — выбери одно:**
- **(а) Оставляем как есть**, RHR остаётся радаром продуктовых идей, а поиск референсов
  делаю через `ask` вручную под запрос.
- **(б) Перенацеливаем** плановый скан на нашу тему — я перепишу термины под
  видео/монтаж/генерацию и добавлю профили («референсы», «инструменты», «идеи»).
- **(в) Две колеи**: плановый скан остаётся про деньги, плюс второй профиль про контент.

Мой голос — **(в)**: колеи не мешают друг другу, а разметка источников уже позволяет.

## Что уже сделано без тебя (для контекста)

- `ask` — ad-hoc поиск по вопросу момента (`python run.py ask "…"`), не пишет в базу без `--store`.
- `hn_search` — поиск по HN через публичный Algolia, без ключа и квоты.
- `youtube_ytdlp` — поиск по YouTube без ключа Google (квотный собрат ел 8000 из 10000 units).
- `grok-x-search` погашен — падал ежедневно на отсутствующем платном ключе.
- SSRF: каждый запрос теперь идёт на IP, который прошёл проверку (DNS rebinding закрыт).
- Тесты: 405 зелёных.
